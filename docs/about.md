# About, community & support

Explore → Settings → About is a separate scrollable page with community links,
project source/license and public GitHub profiles. Maintainer: zuanvfx02.
Contributors are read from the repository API; the maintainer is displayed only
in the maintainer section. Up to the first 100 public contributor records are
used. Missing/empty/private repository data shows an explanatory state.

Public GitHub data is refreshed on opening About, subject to a six-hour cache;
Refresh profiles requests fresh data. Offline or failed requests preserve cached
metadata. Profile pictures are optional and use initials when unavailable.
No access token is required; GitHub rate limits and network failures can apply.

Home includes Support us (developer donation) and Learn more (source code).
External links open the installed browser or compatible app. No message is sent
and no donation is performed automatically.

All new interface labels default to English and are registered in the existing
language_en.xml template. Export a fresh language template to translate the new
labels; older packs continue working and missing keys fall back to English.
GitHub names/bios and project/user identifiers are content, not translated UI.
