# Explore: Material 3 Expressive

Five focused destinations and one direct tuning dashboard.

## Five destinations

Home, Apps, Customization, Monitor and Settings retain their latest structure. Home, library and monitoring layouts are preserved.

## Compact customization

Performance profile and boost, paired Refresh rate and Render engine tiles, then grouped rows for additional tuning, focus, power/temperature and session extras. Simple values use selection dialogs. Complex controls open a direct one-step editor with the matching appbar title and Back action. Default and per-game tuning keep their existing stores.

## Mode separation

Console-only features remain in Handheld. Virtual-floating enablement stays on the overview and its report/test has one diagnostic detail. Game icon wallpaper remains retired. Imported wallpapers, existing feature engines and user data are preserved.

## Expressive, quieter styling

v8.46 uses Material 3 1.5.0-beta02, released 21 October 2026 (stable remains 1.4.0). Explore has its own expressive theme/motion, native interactive and checked settings lists, connected profile/Monitor choices and shape-morphing navigation/Apps controls. Home is more restrained, with a solid tonal banner and quieter default surfaces. Existing features, navigation and stores are retained.
