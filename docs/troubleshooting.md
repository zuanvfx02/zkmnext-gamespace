# Troubleshooting

Identify the symptom, check access and test one change.

## An overlay is missing

Check display-over-other-apps permission, game detection, the game library and service notifications. Some ROMs restrict overlays on certain screens.

If a panel is stuck near an edge, change its dock or reopen it after rotation. Test without other tools to distinguish input problems from layout issues.

## Music is not detected

Select Device Auto and grant notification access. Play a track and check whether Android itself shows media controls. Detection cannot be guaranteed for apps or websites without a MediaSession.

## Zero FPS or missing sensors

Check the FPS backend and access rights. The foreground game must be detected. Some sensors are not exposed by the ROM; missing readings should not be replaced by unlabeled estimates.

## Controller or macro issues

Test the controller using Android's input-device settings. Check Gamepad mode and its legend. For macros, adjust coordinates after rotation or resolution changes and verify access requirements.

## Heat, charging and lost access

Return to defaults/Balance, stop experimenting, then check restoration and access. Do not keep increasing boost when temperatures are already rising.

For bug reports, include app version, Android/ROM, device model, access mode, reproduction steps and expected behavior. Sensor and charging behavior must be checked on real hardware.
