# Profiles and automation

Understand CPU profiles and Android game boost.

## Eco, Balance and Rise

Eco limits load where supported. Balance is the starting point for everyday use. Rise requests higher performance within your access and hardware capabilities.

Android Game boost controls the system game mode, separately from CPU profiles. A ROM or game may ignore the request. Higher FPS is not guaranteed.

## Automatic control and temperature

Auto can select a profile when a game session starts, react to low battery or screen-off, reduce the profile when hot and apply a timeout while a game is in the background.

The adaptive thermal controller reads available sensors and steps profiles down and back up. Sensor values vary by device. Keep manufacturer thermal protection enabled when starting out.

## Actions and preload

RAM cleaning, cache cleanup, restarting a game and fan controls serve different purposes. Fan controls work only on supported devices and interfaces.

Preload reads game files into cache within a budget. Its effect depends on your hardware and cache state; a larger budget does not guarantee better performance. Storage maintenance is separate from deleting cached files.
