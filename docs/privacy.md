# Privacy and connections

Local data, permissions and network activity explained.

## Data on your device

GameSpace does not provide an account or cloud backend for library/settings. Profiles, layouts, music choices, playtime and diagnostic logs are managed locally by the reviewed implementation.

Notification access is sensitive: enable it only for features you use. Source apps and Android control available media metadata.

## Existing connections

The updater contacts GitHub over HTTPS. Ping measurements contact 1.1.1.1 when network/latency tools are active, so the app is not entirely offline.

Destination servers can see your IP address. Music-app and browser providers' policies also apply when you use their services.

## This documentation website

The static documentation UI has no analytics, ads, external fonts or application database. Search runs in your browser, and theme preferences use localStorage when available. Hosting access settings may require visitors to sign in.

The hosting provider may record network requests under its own policies. A static website does not guarantee the absence of server access logs.

## GitHub profiles and external links

About requests public maintainer/contributor information from the GitHub API and avatars from GitHub hosting. Public metadata is cached locally. Endpoint providers can see your IP address.

Community and donation links open external apps or browsers under their own privacy policies. Messages and donations are never submitted automatically.
