# Barrage, focus and anti-mistouch

Control interruptions with clear choices.

## Barrage and bubbles

Grant notification access, select source apps and enable Barrage. Ten styles are available: Starlight, Neon Pulse, Royal Crest, Cyber HUD, Arcade Pop, Inferno, Frost Byte, Sakura Bloom, Toxic Core and Obsidian.

Adjust speed, position, font, opacity, character limit and quick reply. Long messages are limited to three lines with an ellipsis. Previews and notifications use the same bubble builder.

## Focus and calls

DND, heads-up blocking and call popups are separate controls. Some operations require DND access or shell access. Quick reply is available only when a notification provides a compatible reply action.

## Edge protection

Preview corner zones through Game Center > System anti mistouch. During play, these zones are transparent but still capture touch.

Choose Small/Medium/Broad Range. If game buttons become difficult to press, reduce or disable the zone through settings or the session notification. System navigation gestures can still take priority.
