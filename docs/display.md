# Display, rendering and color

Adjust your screen without mixing in kernel settings.

## Settings scope

Display settings can apply to all games by default or to one selected game. Check Apply settings to before changing values. Selecting a game in Display does not make kernel or charging controls per-game.

## Rendering and resolution

Render engine, resolution scale and FPS target depend on access and ROM support. HWUI does not control every native game engine. Requested FPS is not guaranteed FPS.

Some changes appear only after restarting the game. Follow Apply/Restart prompts. Optimize game uses profile compilation and may take time.

## Color

RGB and saturation controls depend on access. Reset restores neutral color through supported interfaces. Enable automatic per-game application only after checking the result.

Experimental renderer and SurfaceFlinger settings are not universal. Save your starting configuration and test one change at a time.
